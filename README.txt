The Roottrees are Dead — Web Edition

LOCAL PLAY
Extract the entire ZIP into one folder, then open index.html in your browser.
Keep all files and subfolders together. Do not open the game from inside the ZIP.
Local play uses the included assets and does not require an Internet connection
or a local web server. Click Start game to begin and allow sound to start.

STATIC WEBSITE
Upload the same extracted folder to a static HTTPS host. index.html is the entry
point. Keep the relative folder structure unchanged. No application server,
database, account, or external asset CDN is required. Assets load as needed.

LANGUAGE
A fresh installation defaults to English, including loading and recovery notices.
You can choose another supported language in Settings. Saved language choices
are retained. Settings labels update immediately; follow the game's restart
notice for already-loaded story text, localized artwork, or voice audio.

FULLSCREEN
Use the game's display setting to enter fullscreen. Press Esc to leave it.
Changing unrelated settings does not force fullscreen back on.

SAVES AND UPDATES
Progress is stored in the current browser profile. Different browsers, website
addresses, local paths, or private-browsing sessions may use separate storage.
Use the main-menu export and import controls to transfer or back up your saves.
Before replacing an older version, export a backup, save and exit, then close
all old game tabs and windows. Keep your backup outside the game folder.
Only one game tab or window can write to the same browser save storage at once.
Do not clear browser data or close the page while a save warning is displayed.

TESTING NOTE
Browser checks were performed on Linux. Chrome and Edge software-rendering
tests showed audio interruptions; smooth audio on Windows hardware has
not been verified.
